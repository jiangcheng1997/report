# 文档结构与提纲规范 (Structure Blueprint)

## 3.1 元结构原则
遵循"倒金字塔+模块化"原则：
- 顶部20%：核心结论/主旨全景（让读者30秒内抓住重点）
- 中部60%：分层论证/展开（每部分可独立阅读）
- 底部20%：总结升华/行动号召（回扣开头，形成闭环）

## 3.2 通用章节骨架
```text
[标题区]
  └─ 标题公式：核心对象 + 关键动作 + 价值指向（限30字内）

[摘要/导语区]（占全文5-10%）
  └─ 三要素：背景（为何写）+ 核心发现（是什么）+ 结构预告（怎么读）

[主体论证区]（占全文60-70%）
  └─ 采用"MECE原则"：相互独立，完全穷尽
  └─ 每章遵循"论点→论据→论证→小结"四步循环

[边界/局限区]（占全文5%，可选）
  └─ 主动声明本文未覆盖的内容或存在的局限

[结论/行动区]（占全文10-15%）
  └─ 不引入新论据，仅整合前文并指向未来
```

## 3.4 段落微观结构
- **起承转合标记**：每段开头使用逻辑路标词（"具体而言"、"反观之"、"值得注意的是"、"从代码角度看"）
- **信息密度**：每段不超过5个信息点，超过则拆分
- **过渡规则**：段与段之间必须有显性连接词或隐性逻辑链（禁止硬跳转）

## 3.5 长度控制公式
- 总字数 = 基础值 × 复杂度系数
  - 基础值：中篇(3000)
  - 复杂度系数：对比分析(1.3)
  - 目标字数：3900字左右（3000-4500字范围）
