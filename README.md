# AI智能体开发教学项目

本项目是一个基于Python的AI智能体开发教学项目，旨在帮助学习者逐步掌握AI智能体的开发技能。

## 项目结构

```
d:\tmp\
├── .env                  # 环境变量配置文件（用户需手动创建）
├── .gitignore           # Git忽略文件配置
├── env.example          # 环境变量配置模板
├── README.md            # 项目说明文档
├── test_env.py          # Python环境测试脚本
├── practice01/          # 练习1目录
│   └── llm_client.py    # LLM客户端实现
├── practice02/          # 练习2目录
│   ├── chat_client.py   # 交互式聊天客户端（流式输出）
│   ├── file_tools.py    # 文件操作工具模块
│   ├── test_file_tools.py # 文件工具测试脚本
│   ├── test_connection.py # 连接测试脚本
│   └── tool_chat_client.py # 支持工具调用的聊天客户端
├── practice03/          # 练习3目录
│   ├── summarize_chat_client.py # 支持聊天记录总结和压缩的聊天客户端
│   └── search_chat_client.py # 支持聊天记录总结、压缩和历史查询的聊天客户端
└── practice04/          # 练习4目录
    ├── anythingllm_query.py # AnythingLLM查询功能实现

```

### file_tools.py
**文件路径**: `d:\tmp\practice02\file_tools.py`

**功能用途**:
- 提供文件操作工具函数
- 支持网络访问功能（curl命令模拟）

**核心功能**:
1. **list_files(directory)**: 列出指定目录下的所有文件及其属性
2. **rename_file(directory, old_name, new_name)**: 修改指定目录下的文件名字
3. **delete_file(directory, file_name)**: 删除指定目录下的文件
4. **create_file(directory, file_name, content)**: 在指定目录下新建文件并写入内容
5. **read_file(directory, file_name)**: 读取指定目录下的文件内容
6. **curl(url, method="GET", headers=None, data=None)**: 网络访问功能，模拟curl命令访问网页并返回内容

**返回格式**:
- 所有函数返回统一的字典格式，包含`status`、`message`等字段
- 成功时`status`为"success"，失败时为"error"
- 具体返回字段根据函数功能有所不同
